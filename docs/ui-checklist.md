# Manual UI checklist (spec §15, §17)

Automatically covered by `crates/shader_editor_app/tests/ui_smoke.rs` (creating a node, connecting
through bevy_noodle, rejecting an incompatible connection, undo, save, move) and
`state::tests` (creating/renaming/moving/deleting assets, auto-connect from the palette,
the prompt on close, curve tab edits, constant table edits and clearing references). `SHADER_EDITOR_INPUT=curve_drag|curve_add` with
`SHADER_EDITOR_OPEN=common/pulse.curve.ron` plays a point drag / double click on a curve. Before a release, walk through by hand on `examples/sample_game`:

- [+] Without arguments the last project opens; a directory without `Cargo.toml`/`assets/` — a message with the reason.
- [ ] Welcome screen (decision 0018): with no project (first launch, File → Close Project) the logo, version, the grey disclaimer, recent projects (hover highlight, a click opens one) and Open / New Project with the hook-up snippet show; New Project on a directory without `Cargo.toml` shows the reason, on a crate creates `assets/` + `shaders/` and opens it; the config appears in `<OS config dir>/fe3dback/bevy-shader-editor/config.ron`.
- [ ] Open / New Project: the system folder picker opens at once (Linux: portal, Windows/macOS: native); choosing a folder opens / sets up the project, cancelling leaves the dialog where Ctrl+V pastes a path copied in another application and Browse... reopens the picker; Copy in a generated-file tab reaches other applications.
- [ ] Main menu logo is sharp at 100–200 % scale; Help → About shows the logo, version, author, license, disclaimer, and the link opens the browser; Help → Project Page too; Help → Quick Start shows the five hook-up steps with the `Cargo.toml` / plugin snippets.
- [ ] Main menu (decision 0016): File opens Open Project / Close Project (asks when dirty; the tabs come back on reopen) / Save / Save All / Quit with right-aligned hotkeys; Assets creates every kind and regenerates; the toolbar after Undo/Redo follows the active tab (graph / curve / generated file).
- [~] Browser: double click opens an asset (a single click does not); only the active tab's asset is highlighted, folders never; unsaved assets show an orange dot; RMB on a folder or the empty space below the tree → New Pbr/Unlit/2D/Fn/Curve/Folder in that folder; RMB → Rename / Move / Delete (with confirmation, autogen is deleted); dragging an asset onto a folder moves it; "Show generated WESL/Rust" opens a read-only tab (code icon, `wesl`/`rust` watermark, highlighted, line numbers; wheel / Shift+wheel scroll; Ctrl+C and the Copy button copy the file; "Open in the default application" works; the tab refreshes after Ctrl+S of its asset; switching back to the graph tab keeps its camera).
- [ ] Icons: browser rows show caret + folder (open/closed) and the asset kind icon (fx / lit sphere / grey sphere / image); tabs, the toolbar and the menus show icons with an orange accent; Undo / Redo are icon-only, hovering a toolbar button shows a tooltip with its hotkey after ~0.5 s (hidden on click); the main view shows a faint `pbr3d`/`unlit3d`/`sprite2d`/`function` watermark bottom-right, above the graph (the minimap is bottom-left); icons stay sharp at a 125–200 % display scale.
- [ ] Tabs: several assets, short names (`rock_wet`; full paths when two open tabs share one, the path as tooltip), compact, wrapping onto more rows when many are open, `*` on unsaved ones, Ctrl+W / × / MMB closes, a dirty tab asks Save/Discard/Cancel; RMB → Close / All / Others / Left / Right / Unmodified (one question for all dirty ones); generated-file tabs are restored on the next launch too.
- [~] Canvas: pan (RMB/MMB drag; releasing RMB after a pan opens no palette and deletes no wire), zoom (wheel), box select, node drag (Ctrl+Z reverts it in one step), compatible-port highlighting while dragging a wire, a wire onto an incompatible port → a message with E002/E003 in the log.
- [+] Palette: Tab and RMB on the canvas; search `*`, `+`, `lerp`, `texture sample`; arrows + Enter; a wire released into empty space → palette with compatible nodes only and auto-connect.
- [+] Hotkeys: `1`/`2`/`3`/`4`/`S`/`T`/`M`/`A`/`L` + LMB, Ctrl+C/V/X/D, Delete, F, Home, C (frame), Ctrl+L (auto-layout).
- [+] Reroute: double click on a wire; RMB on a wire deletes it. Ctrl+LMB on a wire deletes it, on a pin deletes all its wires (one Ctrl+Z).
- [ ] Named route: "Named Route" from the palette, then "Named Route Usage: {name}"; the usage takes the declaration's type; Route select in the properties; renaming the declaration renames the usages; a loop through a route is refused (E002).
- [ ] Inline editors: Lerp Alpha slider drags without moving the node and is one Ctrl+Z; a number field takes typed text and Delete/Ctrl+Z go to the field, not the graph; Float3/Float4/Color show only the color button, it opens the picker and Properties' R/G/B fields follow it after release; a wire hides the pin's editor; the node's selected Properties show the new value after release.
- [ ] Pin menu: RMB on Lerp A → Float3 turns A/B/out into Float3 (color editors), back to Float; Reset to default; Disconnect on a wired pin.
- [ ] Node menu (decision 0021): RMB click on a node body opens it (an RMB pan does not, RMB on a pin keeps the pin menu, an unselected node gets selected first); Add / Subtract / Multiply / Divide list "Convert to" the other three with `Shift +` / `Shift -` / `Shift *` / `Shift /` right-aligned, then Exclusive preview (materials only), Copy / Duplicate / Delete.
- [ ] Convert: via the menu and with `Shift + - * /` (main row and numpad) on the selection — wires and values stay, one Ctrl+Z reverts it; with several selected nodes all convertible ones change; the keys do nothing while typing in a field.
- [ ] Constant Label: Constant / 2/3/4Vector have a Label row in Properties; a non-empty label replaces the value in the node title, clearing it shows the value again; the generated files do not change.
- [ ] Exclusive preview (decision 0022): `V` on one selected material node (on release; `V` + LMB on empty canvas only drops a Vector parameter) and "Exclusive preview" in the node menu toggle it; the previewed node has a thick orange border and an orange warning icon before its title, the tab title shows `(preview)`, the tab turns unsaved, the generated WESL has the `// preview of node …` header and the running sample game shows the node's output; another node moves the preview, `V` / "Stop preview" turns it off; the MaterialOutput and nodes without a color-like output show "Exclusive preview (not available)" (a log message); function graphs have no preview row.
- [ ] Preview mode: Properties → Preview → Mode `Unlit` / `Lit` / `Full` regenerates at once (header `(lit)` …) and is remembered while no node is previewed ("No node previewed - select a node and press V").
- [ ] Preview discard: Ctrl+Z of the toggle, deleting the previewed node and closing the tab with Discard put the normal WESL back; Ctrl+S stores `preview` in the `.ron`.
- [ ] Material Attributes (decision 0023): Properties of a Pbr3d material have Output `Default` / `Wrapped`; switching to `Wrapped` leaves the output node with `Material Attributes` + World Position Offset, drops the wires into the vanished pins (a WPO wire stays), and one Ctrl+Z brings back the old pins, wires and inline values; switching back drops the `attributes` wire the same way.
- [ ] MakeMaterialAttributes (PBR) → Lerp A and B connects (purple wires), the Lerp output then only connects to attribute inputs; Make → Add / Multiply / If and Make → Lerp B while a Float3 feeds Lerp A are refused with E003 in the log (also the other order); dropping a Make wire on empty space offers Lerp and Break in the palette.
- [ ] Preview a Make node with `V` in each mode: `unlit` / `lit` show its Base Color, `full` also roughness / metallic / normal …; works with the material in `Default` and in `Wrapped`.
- [ ] Double click on a function call node opens the function's tab (a second double click on another call switches to the already open tab), on a Sample Curve node the curve, on a Global* node the constant table; nothing happens on a user node, on a Sample Curve without a curve, on a pin or inside an inline value field; Properties show "Open function" / "Open curve" / "Open constant table".
- [ ] Known: at zoom ≠ 1 a slider moves faster/slower than the cursor and the color picker opens off its button (Bevy 0.20, decision 0012).
- [+] Comment frame: dragging the frame moves the nodes inside; the title is edited in the properties.
- [+] Minimap: click/drag moves the view.
- [+] Properties: node parameters (numbers, vectors, color, bool, enum, pin type, text, Custom code), input default values, asset blend mode / two-sided / shading / output; changes show on the nodes immediately.
- [+] Log: errors/warnings appear live, nodes are outlined; clicking a line opens the asset and focuses the node.
- [+] Ctrl+S: save and regenerate; with `examples/sample_game` running the picture updates without a restart.
- [ ] Changing a graph file externally (git checkout): a clean tab reloads, a dirty one asks Reload / Keep mine.
- [ ] Curves (decision 0015): `+Curve` creates a ramp and opens it (spline icon, `curve` watermark); double click adds a point, drag moves the selection (one Ctrl+Z, points may pass each other; X / Y held lock the axis, Shift held snaps to 0.1), Shift+click toggles, Ctrl+A / Delete / Ctrl+C/V/D / arrows (Shift ×10) work, RMB on a point / empty space opens its menu; the header switches the preview between Catmull-Rom and Simple without marking the tab dirty; Properties edit the selected point's T / Value and list the hotkeys one per line; Ctrl+S regenerates `autogen/curves/…` and the running sample game updates `curve_bands`; a clean curve tab reloads on an external change.
- [ ] Sample Curve node: the Curve select lists the project's curves, "Open curve" opens it, the title shows the curve name; the node's mini plot follows the type, the inline T slider (a vertical line, gone when T is wired) and unsaved edits in the curve tab, and shows "n/a" without a curve; renaming the curve updates the node; deleting it gives E006 on the node.
- [ ] Global constants (decision 0017): Assets → New Global Consts opens an empty table (table icon, `consts` watermark); the add form refuses a bad name or one used in any table (red text under the form), Enter or Add adds the row and empties the field; the toolbar has no Add button; f32 is a number field taking any value (e.g. -37.5, 250) plus a slider 0..1 that widens to a typed value outside it (-37.5 → -100..100) and follows the field (and the other way round), vecN a color picker whose R/G/B(/A) fields follow it (and the other way round, any typed value), bool/compileFlag a checkbox; a slider or picker drag is one Ctrl+Z; a new row starts at 1.0 / checked; changing a type without readers converts the value at once, with readers asks first (Cancel keeps the old type in the select) and OK saves the table and clears the nodes' references (clean open graphs are saved, the log names the graphs); deleting a row, Ctrl+Z / Ctrl+Y of such a change and deleting the table file in the browser behave the same; Ctrl+S regenerates the shaders reading the table and the running sample game updates `global_tint`.
- [ ] Global* nodes: Properties list only constants of the node's type ("(missing)" for a deleted one, "(is vec3)" for one of another type), "Open constant table" opens it; the title shows the name; the preview shows the number / color square / green `1` or grey `0` square with a check mark, follows unsaved edits in the table tab, and "n/a" without a constant; GlobalCompileFlag connects only to Bool inputs.
- [~] Closing the window with unsaved changes — a prompt; window size and tabs are restored on the next launch.
